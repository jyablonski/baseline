# 0005: No followed-team module on the home page or `/teams`

**Status:** Accepted. **Decided:** 2026-11-15.

## Context

A "Your teams" table for followed teams was tried on the home page and on `/teams`. Both added clutter to pages meant to stay general.

## Decision

No followed-team status module on hub pages. Followed teams personalise existing surfaces lightly (tinted standings rows, ordering, shortcuts) or get a dedicated place.

## Consequences

- New followed-team features show insight, not a status table, and their placement is agreed before building.
